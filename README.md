# Vehicle Possession Search

موقع ثابت للبحث عن الحيازات بآخر 7 خانات من رقم الحيازة.

## طريقة عمله
- يقبل الحروف والأرقام.
- البحث غير حساس لحالة الأحرف: `c05638` = `C05638`.
- تتم مطابقة آخر 7 خانات من قيمة `code`.
- ملفات الحيازات نفسها لا تُرفع إلى GitHub؛ يوضع رابط OneDrive في `data.json`.
- زر "فتح / حفظ" يفتح رابط OneDrive في المتصفح. سلوك التحميل النهائي يعتمد على إعدادات مشاركة OneDrive ونوع الرابط.

## ملف data.json
لكل حيازة أضف سجلًا بهذا الشكل:

{
  "code": "0001234567",
  "title": "حيازة 0001234567",
  "url": "رابط OneDrive هنا"
}

مهم:
- `code` هو رقم الحيازة كما هو، ويمكن أن يحتوي على حروف وأرقام.
- الموقع يقارن آخر 7 خانات فقط.
- لا تضع ملفات الحيازات أو بيانات حساسة داخل المستودع.

## تشغيل الموقع
ارفع:
- index.html
- style.css
- app.js
- data.json

ثم فعّل GitHub Pages من Settings > Pages واختَر النشر من فرع `main` ومن مجلد `/ (root)`.
